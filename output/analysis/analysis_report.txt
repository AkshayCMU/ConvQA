================================================================================
                              KEY FINDINGS
================================================================================

1. RAG IMPROVEMENT: 127% improvement over baseline
   - Best RAG system: 3.93 vs Baseline: 1.73
   - Retrieval is essential for domain-specific QA

2. QUESTION DIFFICULTY HIERARCHY:
   - Factoid (easiest): Single fact lookup, all RAG systems perform well
   - MCQ (moderate): Requires reasoning, GPT-4o-mini excels
   - List (hardest): Multi-hop aggregation, only best system succeeds

3. RETRIEVER SELECTION:
   - Hybrid > Semantic > None
   - BM25 handles exact matches (numbers, names)
   - Dense retrieval handles conceptual similarity
   - RRF fusion combines benefits of both

4. GENERATOR SELECTION:
   - GPT-4o-mini >> Qwen2.5:1.5b
   - Model size matters for complex reasoning
   - Instruction following critical for QA format

5. FAILURE PATTERNS:
   - Numerical extraction from tables (Q4, Q6)
   - Multi-item list aggregation (Q4, Q13)
   - Format mismatch between prediction and ground truth
